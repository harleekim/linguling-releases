1. 개인정보처리방침의 목적

흐안느아(이하 “개발자”)는 영어 학습 앱 링구링(LinguLing, 이하 “앱”)을 운영하며 사용자의 개인정보를 중요하게 생각합니다. 이 방침은 앱이 어떤 정보에 접근하고 이를 어떻게 이용·보관하는지 설명합니다.

2. 개발자가 직접 수집하는 개인정보

앱은 회원가입을 요구하지 않으며, 개발자는 이름, 이메일, 전화번호, 위치, 연락처 또는 광고 식별자를 직접 수집하거나 별도의 개발자 서버에 저장하지 않습니다.

3. 기기에 저장되는 학습 데이터

사용자가 작성한 영어·한국어 카드, 발음기호, 태그, 단어장, 정답 및 오답 횟수와 최근 학습 기록은 사용자의 기기 내부 저장소에 저장됩니다. 개발자는 이 데이터에 접근할 수 없습니다.

사용자가 전체 데이터 또는 단어장을 내보내면 사용자가 선택한 앱이나 저장 위치로 파일이 전달됩니다. 이 과정은 사용자의 명시적인 요청으로만 시작되며, 전달 이후에는 선택한 서비스의 개인정보처리방침이 적용됩니다.

4. 마이크와 음성 인식

앱은 영어 말하기 답안을 인식하기 위해 사용자가 기능을 선택하고 권한을 허용한 경우에만 마이크를 사용합니다. 앱과 개발자는 음성 녹음 파일을 자체 서버에 저장하지 않습니다.

음성 인식은 기기 또는 운영체제에서 제공하는 음성 인식 서비스에 의해 처리될 수 있으며, 서비스 제공 방식에 따라 음성 데이터가 Google 등 해당 음성 인식 제공자에게 전송될 수 있습니다. 이 경우 해당 제공자의 개인정보처리방침이 적용됩니다.

5. 외부 서비스 이용

  • 발음기호 자동 조회를 요청하면 입력한 영어 단어가 Dictionary API(dictionaryapi.dev)에 전송될 수 있습니다.
  • 네이버 영어사전에서 확인하기를 선택하면 검색어가 포함된 외부 브라우저 페이지가 열립니다.

외부 서비스에서 처리되는 정보에는 각 서비스의 이용약관 및 개인정보처리방침이 적용됩니다.

6. 데이터 공유 및 판매

개발자는 사용자의 개인정보나 학습 데이터를 판매하지 않습니다. 또한 법령에 따른 의무가 있는 경우를 제외하고 개발자가 보유하지 않은 사용자 데이터를 제3자에게 제공하지 않습니다.

7. 보관 및 삭제

학습 데이터는 사용자가 앱에서 삭제하거나 앱의 저장 데이터를 지울 때까지 기기에 보관됩니다. 앱을 삭제하면 운영체제의 동작에 따라 기기에 저장된 앱 데이터도 삭제됩니다. 내보낸 백업 파일은 사용자가 직접 삭제하거나 보관해야 합니다.

8. 아동의 개인정보

앱은 아동의 개인정보를 의도적으로 수집하지 않습니다. 개발자가 아동의 개인정보를 수집한 사실을 알게 되는 경우 지체 없이 필요한 조치를 취합니다.

9. 방침 변경

앱의 기능이나 관련 법령이 변경되면 이 방침을 수정할 수 있습니다. 중요한 변경이 있는 경우 앱 또는 이 페이지를 통해 알리고 시행일을 갱신합니다.
