아래 파일은 링구링 앱의 **단어장 가져오기** 기능으로 불러올 수 있습니다.

## 사용 방법

1. 원하는 JSON 파일을 휴대폰에 다운로드합니다.
2. 링구링에서 **단어장 → 카드 가져오기**를 선택합니다.
3. 다운로드한 파일을 선택합니다.

비영리 목적으로 공유하거나 수정할 수 있습니다.
